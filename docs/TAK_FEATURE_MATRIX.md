# God's Eye View × TAK capability and parity matrix

Updated: 2026-10-16. Integration branch: `dev/tak-web-foundation` in
`rebeltechoxford/gods-eye-view`. The inspected remote baseline is
`aee71aba3e39f908c4df4cf797108ab472b9ee4d`; this matrix also records the additive
gateway hardening work built on that baseline. Final execution evidence belongs
in [the implementation plan](TAK_IMPLEMENTATION_PLAN.md).

This is a scope inventory and acceptance ledger, not a claim of complete ATAK
parity. A parsed CoT fixture, passing unit test, or working marker demonstrates
only the behavior exercised. ATAK-CIV, iTAK and WinTAK versions and plugins differ;
each real interoperability result must name the peer version and transport.

## Evidence levels

| Level            | Meaning                                                                                                                                                                                                  |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Existing GEV     | Present in the inspected application/catalog and upstream documentation. Runtime availability still depends on keys, providers and hardware; this label does not mean every feature was re-tested today. |
| Local foundation | Implemented in the additive TAK foundation. Portable, socket/TLS and browser checks cover different subsets; local test success never implies real-peer interoperability.                                |
| Candidate        | Source exists outside the inspected integration baseline. Requires review, hardening, integration and evidence before promotion.                                                                         |
| Planned          | No accepted implementation or verification for the stated TAK workflow.                                                                                                                                  |
| Companion/bridge | Needs a native process, hardware, authorized external service or plugin; browser code alone cannot promise the capability.                                                                               |
| Live verified    | Reserved for an observed exchange with a named real TAK peer/server and recorded result. No row currently qualifies.                                                                                     |

## Licensing and reuse boundary

The repository's [MIT license](../LICENSE) covers source code, with its existing
copyright notice retained. [DATA_SOURCES.md](../DATA_SOURCES.md) and
[model provenance](../public/models/README.md) document separate data/asset terms.
TeleGeography cable data is CC BY-NC-SA 3.0; Bhote Koshi imagery and derived
coordinates are CC BY-NC 4.0. OSM-derived data has ODbL obligations. Existing
provider credentials or inclusion in GEV do not grant additional use rights.

The official [ATAK-CIV source repository](https://github.com/deptofdefense/AndroidTacticalAssaultKit-CIV)
identifies separate dependency notices, and its
[license file](https://github.com/deptofdefense/AndroidTacticalAssaultKit-CIV/blob/main/LICENSE.md)
contains GPLv3 terms. Treat it as a protocol/workflow reference. Review the
specific component and third-party notices before copying, linking or
redistributing anything; Android plugins do not become browser code by virtue
of being available. The [TAK product FAQ](https://tak.gov/faq) is a primary
reference for the product family, not evidence that this client implements it.

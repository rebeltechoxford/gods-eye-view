# FIS-B test fixtures

Used only by `src/sources/fisb/*.test.mjs` and `src/data/fisbProxy.test.mjs`;
never loaded at runtime.

- `tg28.978`, `tg29.978` — FIS-B test groups 28 and 29 in dump978-fa raw
  format (`+<864 hex>;…`), and `tg30-subset.978` — 64 of the 963 uplinks of
  test group 30, chosen to cover every product (up to six frames each,
  NEXRAD frames with precipitation, and two complete segmented products).
  These test groups were generated by Michael Barnes for
  [fisb-decode](https://github.com/rand-projects/fisb-decode)
  (`tg/tg-source/generated/`, commit `c3d3b04`, 2022-09-05).
- `*.level0.jsonl` — fisb-decode's level-0 decode of the same uplinks (one
  JSON line per uplink that carries APDU, current-report-list or
  service-status frames), produced by running fisb-decode at that commit. The
  decoder tests compare every frame field by field against these lines; the
  implementation under test was written independently from the GDL 90 public
  ICD and does not contain fisb-decode code.
- `icd-nexrad-sample.txt` — the two 424-byte sample application data fields
  of section 5.1.4 of the GDL 90 Data Interface Specification
  (560-1058-00 Rev A, Garmin, public document), a NEXRAD test pattern over
  northern Oregon.
